# 웹툰 알림판 (webtoon_clock)

네이버웹툰 · 네이버 시리즈 · 카카오페이지에서 보는 작품을 **한 화면에 모아 두고**, 누르면 바로 그 앱으로 넘어가는 개인용 알림판이에요.

- 화면 주소: <https://sh11025.github.io/webtoon_clock/>
- 설치 없이 크롬에서 열면 돼요. 크롬 메뉴(⋮) → **홈 화면에 추가**를 하면 앱처럼 쓸 수 있어요.
- 이 보관함에는 화면 파일(`index.html`) 하나만 있어요. **개인 목록이나 열쇠는 들어 있지 않아요.**

---

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 한곳에 모아 보기 | 위쪽 탭에서 네이버 · 시리즈 · 카카오를 골라 봐요 |
| 요일별 보기 | 오늘 요일이 먼저 선택돼 있어요. 자정이 지나면 자동으로 다음 요일로 바뀌어요 |
| 비정기 · 휴재 · 완결 | 요일 버튼 오른쪽에서 따로 모아 봐요. 요일을 비워 둔 연재 중 작품은 ‘비정기’에 모여요 |
| 누르면 앱으로 이동 | 작품을 누르면 해당 웹툰 앱(또는 사이트)이 열려요 |
| 공유 글로 추가 | 웹툰 앱의 **공유 → 링크 복사**로 받은 글을 그대로 붙여 넣으면 제목까지 들어가요 |
| 여러 개 한 번에 추가 | 한 줄에 하나씩 붙여 넣으면 돼요. 세 플랫폼을 섞어도 되고, 쉼표·띄어쓰기로 구분해도 알아봐요 |
| 겹치는 작품 걸러내기 | 이미 있는 작품은 빼고 알려 줘요 |
| 제목으로 검색 | 제목을 입력하면 세 플랫폼에서 찾아 줘요 (깃허브 연결 + 자동 작업 필요) |
| 표지 · 요일 자동 채우기 | 표지 그림, 작가, 연재 요일, 완결 여부를 자동으로 채워요 (깃허브 연결 + 자동 작업 필요) |
| 정렬 | 가나다순 / 최근 추가순 |
| 기기끼리 같은 목록 | 휴대폰 · 태블릿 · PC가 같은 목록을 봐요 (깃허브 연결 필요) |
| 백업 | 목록을 파일로 내보내고 가져올 수 있어요 |

화면 크기에 맞춰 모양이 바뀌어요. 휴대폰은 **작은 표지 + 제목 목록**, 태블릿은 **큰 표지 책장**이에요.

## 그냥 써 보기 (연결 없이)

1. <https://sh11025.github.io/webtoon_clock/> 를 열어요.
2. 오른쪽 위 **⚙ 설정 → 작품 추가**에 작품 주소나 공유 글을 붙여 넣고 **추가**를 눌러요.

이렇게만 써도 돼요. 다만 목록이 **그 기기의 크롬 안에만** 저장돼요. 여러 기기에서 같이 보거나 표지를 자동으로 채우려면 아래 ‘내 목록 보관함 연결하기’를 해 주세요.

---

## 내 목록 보관함 연결하기

화면은 같이 써도 **목록은 사람마다 따로** 저장돼요. 각자의 비공개 보관함에 저장되고, 내 열쇠가 있어야만 열 수 있어요.

깃허브 계정이 필요해요. 없으면 <https://github.com/signup> 에서 먼저 만드세요.

### 1단계. 목록 보관함 만들기 (비공개)

1. <https://github.com/new> 를 열어요.
2. **Repository name**: 원하는 이름 (예: `webtoon_clock_data`)
3. **Choose visibility**: **Private** (꼭 비공개로)
4. **Add README**: **On**
5. **Create repository**를 눌러요.

`list.json`(목록 파일)은 알림판이 처음 연결될 때 자동으로 만들어요.

### 2단계. 열쇠 만들기

알림판이 내 목록 보관함을 읽고 쓸 수 있게 허락해 주는 "열쇠"예요. 깃허브에서는 **Fine-grained personal access token**이라고 불러요.

1. <https://github.com/settings/personal-access-tokens/new> 를 열어요.
2. 아래처럼 채워요.

| 항목 | 넣을 값 |
|---|---|
| Token name | 아무거나 (예: `웹툰 알림판`) |
| Expiration | 사용 기간 (개인용이면 1년 정도). **끝나는 날짜를 기억해 두세요** |
| Repository access | **Only select repositories** → 1단계에서 만든 보관함 **하나만** |
| Permissions → Repository permissions → **Contents** | **Read and write** |
| 그 밖의 권한 | 건드리지 않아요 |

3. **Generate token**을 누르면 `github_pat_...`로 시작하는 글자가 나와요. 이 화면을 벗어나면 다시 볼 수 없으니 바로 복사해 두세요.

> 보관함 하나, Contents 권한만 주는 이유: 열쇠가 혹시 새어 나가도 그 목록 파일 말고는 아무것도 건드릴 수 없게 하기 위해서예요.

### 3단계. 알림판에 연결하기

1. 알림판에서 **⚙ 설정 → 깃허브 연결**을 열어요.
2. 세 칸을 채워요.
   - **목록 보관함**: `내아이디/보관함이름` (예: `hong/webtoon_clock_data`)
   - **열쇠**: 2단계에서 복사한 `github_pat_...`
   - **열쇠 기한 (선택)**: 열쇠가 끝나는 날짜. 적어 두면 끝나기 2주 전부터 ⚙ 아이콘에 빨간 점으로 알려 줘요.
3. **연결**을 누르고 "연결됨" 또는 "저장됨"이 보이면 성공이에요.

다른 기기에서도 3단계만 똑같이 하면 같은 목록이 보여요. 열쇠를 다른 기기로 옮길 때는 카카오톡 "나와의 채팅" 등을 쓰고, **옮긴 뒤에는 그 메시지를 지워 주세요.**

### (선택) 표지 자동 채우기 · 제목 검색 켜기

표지 그림, 작가, 연재 요일을 자동으로 채우고 **제목으로 검색**하려면, 목록 보관함에 파일 두 개를 더 올려야 해요.

| 파일 위치 | 하는 일 |
|---|---|
| `scripts/webtoon_meta.py` | 웹툰 사이트에서 작품 정보를 찾아오는 프로그램 |
| `.github/workflows/webtoon.yml` | 목록이 바뀔 때와 매일 새벽에 위 프로그램을 깃허브가 대신 실행 |

- 두 파일은 알림판을 알려 준 사람에게 받아 주세요.
- 올리는 방법: 목록 보관함에서 **Add file → Create new file** → 이름 칸에 `scripts/webtoon_meta.py`처럼 폴더까지 적고 → 내용을 붙여 넣고 → **Commit changes**.
- 이 파일이 없어도 알림판은 잘 돌아가요. 표지 대신 제목 첫 글자가 보이고, 제목 검색만 안 돼요.
- 깃허브의 자동 실행은 비공개 보관함 기준 한 달 2,000분까지 무료예요. 한 번에 1분 정도라 넉넉해요.
- 정보 확인은 깃허브 컴퓨터가 해서, 내 인터넷 주소(IP)는 웹툰 사이트에 드러나지 않아요.

## 동기화는 이렇게 돼요

- **켤 때 한 번** 깃허브에서 목록을 받아와요. 띄워 둔 채 1시간 넘게 지났다가 다시 보면 조용히 한 번 더 받아와요.
- **저장은 모아서 한 번** 해요. 편집 중이면 **완료**를 누를 때, 아니면 추가하고 2초쯤 뒤에 저장해요. 다른 앱으로 넘어갈 때 남은 게 있어도 저장해요.
- 저장할 때는 깃허브의 최신 목록을 먼저 받아서, **그 기기에서 바꾼 것만** 얹어 저장해요. 오래 안 쓴 기기에서 저장해도 다른 기기에서 넣은 작품이 지워지지 않아요.
- 저장이 끝났는지는 **⚙ 설정 → 깃허브 연결**의 "저장됨 · 시각"으로 확인해요.
- 표지 · 제목 · 요일은 저장하고 1~3분 뒤에 채워져요.

깃허브는 모든 저장 기록을 남겨요. 혹시 목록이 이상해지면 목록 보관함의 `list.json` → **History**에서 예전 내용을 찾을 수 있어요.

## 넣을 수 있는 주소

| 플랫폼 | 주소 예시 |
|---|---|
| 네이버웹툰 | `https://comic.naver.com/webtoon/list?titleId=숫자` · 앱 공유 주소 `https://m.comic.naver.com/share/...` |
| 네이버 시리즈 | `https://series.naver.com/comic/detail.series?productNo=숫자` · 앱 공유 주소 `https://naver.me/...` |
| 카카오페이지 | `https://page.kakao.com/content/숫자` · 앱 공유 주소 `https://link-page.kakao.com/open/content?series_id=숫자` |

- 시리즈는 **작품 페이지** 주소를 넣어 주세요. 한 권짜리 페이지(`volumeDetail`)는 표지를 못 찾아요.
- 주소만 한 줄에 하나씩 적은 `.txt` 파일도 **⚙ 설정 → 가져오기**로 불러올 수 있어요.

## 연결이 안 될 때

| 알림판에 뜨는 말 | 확인할 것 |
|---|---|
| 열쇠가 맞지 않거나 기한이 끝났어요 | 열쇠를 끝까지 복사했는지, 기한이 지나지 않았는지. 새 열쇠는 **열쇠 바꾸기**로 넣어요 |
| 열쇠 기한이 ○일 남았어요 | 새 열쇠를 미리 만들어 **열쇠 바꾸기**로 넣어요 |
| 열쇠에 이 보관함을 쓸 권한이 없어요 | 2단계의 **Contents**가 **Read and write**인지 |
| 보관함을 찾지 못했어요 | `아이디/보관함이름` 철자, 열쇠를 만들 때 이 보관함을 골랐는지 |
| 인터넷이 안 돼서 이 기기에만 저장했어요 | 인터넷이 다시 되면 자동으로 저장돼요 |

화면이 바뀐 뒤 예전 모습이 보이면, 알림판을 **완전히 닫았다가 다시 열어** 주세요.

## 안전하게 쓰기

- **열쇠는 비밀번호와 같아요.** 다른 사람에게 보내거나 이런 공개된 곳에 적지 마세요.
- 열쇠는 연결한 기기의 크롬 안에만 저장돼요. 크롬 사이트 데이터를 지우면 열쇠도 지워지니, 3단계를 다시 하면 돼요.
- 열쇠가 새어 나간 것 같으면 <https://github.com/settings/personal-access-tokens> 에서 그 열쇠를 **Delete** 하세요.
- 목록 보관함은 꼭 **Private**으로 두세요.
- 친구에게 알려 줄 때는 이 화면 주소만 알려 주고, 목록 보관함과 열쇠는 **각자 만들게** 해 주세요.

## 내 주소로 따로 올리고 싶다면

1. <https://github.com/new> 에서 **Public**(공개) 보관함을 만들어요. 무료 계정은 공개 보관함이어야 웹페이지 주소를 만들 수 있어요.
2. 이 보관함의 `index.html`을 내려받아 내 보관함에 **Add file → Upload files**로 올리고 **Commit changes**를 눌러요.
3. 내 보관함의 **Settings → Pages**에서 Branch를 `main`, `/ (root)`로 고르고 **Save**를 눌러요.
4. 1~2분 뒤 `https://내아이디.github.io/보관함이름/` 으로 열려요.

화면 파일에는 개인 정보가 없어서, 주소가 공개돼도 다른 사람에게는 빈 화면만 보여요.
